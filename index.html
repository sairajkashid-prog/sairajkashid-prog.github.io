How I work

Patterns that show up across all of these repositories.

🧪

Tested, not just written

CI workflows with property-based and differential tests. The GPU test framework repo ships 133 passing cases and 4 planted bugs that every naive allclose test misses.

📊

Real data, stated limits

CISA KEV, FIRST EPSS and openFDA are live public sources — and each README documents exactly what the analysis cannot claim. Facts separated from inference.

🔁

Idempotent by default

ETL runs are safe to re-run: business keys stay unique, failed rows are quarantined not dropped, and source-to-target totals reconcile on every load.

🚀

Deployed, not demoed

Every project here has a public URL. Static builds, hash routing and relative asset paths so nothing 404s when it leaves localhost.

📄

Research output

Co-author on “Security of LLM-Based AI Agents against Indirect Prompt Injection” — a four-layer defence pipeline for resume screening, with a 60-PDF synthetic benchmark and ablation suite.

🧱

From-scratch systems

GPU particle physics engine (PBD/PBF, C++17 + CUDA behind one C ABI), batched MPPI motion planning for robot fleets, and GPU health drift detection — no frameworks.
